University Management System

A Python-based University Management System designed to manage student information, grades, and attendance.

Features

- Manage student information.
- Record and manage student grades.
- Calculate student GPA.
- Record student attendance.
- Calculate attendance percentages.
- Organize the project using separate Python modules.

Project Structure

University-Management-System/
│
├── main.py
├── models.py
├── data_manager.py
├── grading.py
└── attendance.py

Modules

"models.py"

Contains the main data models used by the system, such as student-related information.

"data_manager.py"

Responsible for managing and handling the system's data.

"grading.py"

Handles student grades and GPA calculations.

"attendance.py"

Handles attendance records and calculates attendance percentages.

"main.py"

The main entry point of the application.

Technologies

- Python 3
- Object-Oriented Programming (OOP)
- Modular Programming

Purpose

This project was developed as a university project to practice Python programming, object-oriented programming, data management, grading, and attendance management.

How to Run

Make sure Python 3 is installed, then run:

python main.py
